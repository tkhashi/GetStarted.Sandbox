# Quickstart: TaskFlow

## 前提

- Node.js (LTS)
- npm

## セットアップ

```bash
npm install
```

## 開発サーバ起動

```bash
npm run dev
```

## ビルド

```bash
npm run build
```

## プレビュー

```bash
npm run preview
```

## データ保存

- タスクとタイムブロックはブラウザの IndexedDB に保存される
- データはローカル端末内で完結し、サーバ同期は行わない
